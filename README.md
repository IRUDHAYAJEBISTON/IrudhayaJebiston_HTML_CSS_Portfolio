# Irudhaya Jebiston — Personal Portfolio Website

A modern, responsive, and accessible personal developer portfolio website developed using pure **HTML5** and **CSS3**.

Designed for an HTML & CSS internship project, this portfolio showcases academic background, core technical skills, and two real-world technology initiatives: **BlueNet (Fisheries Management System)** and **CivicEye AI (Public Problem Reporting System)**.

---

## 🌟 Highlights

- **Pure HTML5 & CSS3:** 100% frontend standard compliance — no JavaScript, no frameworks, no external CSS libraries.
- **Modern Dark UI Design:** Inspired by contemporary technology websites with a dark navy palette, electric blue accents, and turquoise highlights.
- **Responsive Layout:** Fluid layout built with CSS Grid and Flexbox, tested across desktop, tablet, and mobile devices.
- **Pure CSS Visuals:** Features an interactive developer code terminal and custom project graphics built entirely with CSS.
- **Accessibility & Semantics:** Fully semantic HTML5 structure with visible focus states and high-contrast typography.

## 🚀 Projects Showcased

### 1. BlueNet — Fisheries Management System
*Fisheries Technology | Digital Fisheries Ecosystem*
- A digital fisheries platform concept designed to bridge artisanal fishermen with local buyers, provide transparent daily market price indices, and streamline coastal service access.
- **Interface Concepts:** Digital Fish Marketplace, Price Information, Digital Orders, Fisheries Services Directory, User Dashboards.
- **Proposed Future Modules:** Weather notices and vessel location tracking concepts.

### 2. CivicEye AI — Public Problem Reporting System
*Civic Technology | Smart Governance*
- A civic technology portal designed to streamline municipal issue tracking, categorise infrastructure defects (damaged roads, waste accumulation, streetlights), and empower citizens to report local public concerns.
- **Core Modules:** Public Complaint Reporting, Issue Categorisation, Complaint Status Tracking, Administrator Dashboard.
- **Proposed Future Modules:** Geolocation tagging, AI-assisted duplicate complaint detection, and visual summary analytics.

## 💻 How to Run Locally

### Option 1: Direct File Launch
Double-click `index.html` or drag it into any modern web browser (Chrome, Edge, Firefox, Safari).

### Option 2: Localhost Server (Node.js)
```bash
node server.js
```
Then navigate to:
```
http://localhost:3000
```
